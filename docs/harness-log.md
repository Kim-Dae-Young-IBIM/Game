# 하네스 실패 기록

에이전트가 틀리거나 사람이 다시 고쳐야 했던 것을 한 줄씩 적는다. 쌓이면 `/harness-review`로 승격 위치를 정한다.

- 같은 실수 2회 → CLAUDE.md 또는 .claude/rules/
- 같은 절차 3회 → .claude/skills/
- 반드시 막아야 함 → .claude/harness.json (훅이 강제)

| 날짜 | 현상 | 원인 추정 | 횟수 | 조치 (승격 위치) |
|---|---|---|---|---|
| 예시 | 보고서에 출처 없는 수치 기재 | 출처 표기 규칙 미기재 | 1 | |
