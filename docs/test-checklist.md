# 실기기 테스트 체크리스트 (1단계)

대상: LG 75QNED90(webOS 6.5 브라우저), Galaxy S26(Chrome, 삼성 인터넷), iPhone 16 Pro(Safari).
각 항목 옆 칸에 ○/✕와 메모를 적는다. 문제가 나오면 `docs/harness-log.md`에도 한 줄 남긴다.

## 0. 준비

| # | 확인 | 결과 |
|---|---|---|
| 0-1 | PC에서 `npm ci && npm run build && npm start` 실행, `http://localhost:3000/` 열림 | |
| 0-2 | `npm run tunnel`(ngrok) → `https://….ngrok…` 주소 발급 | |
| 0-3 | TV·폰이 모두 인터넷에 연결됨(터널은 외부 주소라 같은 와이파이가 아니어도 됨) | |

> 센서 권한은 HTTPS에서만 나온다. 폰은 반드시 ngrok `https://` 주소로 접속한다. TV도 같은 주소로 연다(QR이 TV 주소 기준으로 만들어진다).
> ngrok 무료 주소는 첫 접속 시 경고 페이지가 나올 수 있다 → "Visit Site"를 한 번 누른다(TV는 리모컨 포인터로).

## 1. TV — webOS 6.5 브라우저

| # | 확인 | 결과 |
|---|---|---|
| 1-1 | 웹 브라우저 앱에서 터널 주소 입력 → `/tv/`로 이동, 무대·고양이·QR·4자리 코드가 보인다 | |
| 1-2 | 화면이 잘리지 않고 16:9 전체에 맞는다(가장자리 검은 띠는 OK) | |
| 1-3 | 시작 버튼에 처음부터 포커스(노란 테두리) → 리모컨 **OK** 한 번으로 시작된다 | |
| 1-4 | 시작하면 "둥" 소리가 난다(소리 잠금 해제 확인). 안 나면 TV 볼륨·외부 출력 확인 | |
| 1-5 | 시작 후 QR·코드가 오른쪽 위로 작아지고, 바닥의 불빛 4개가 박자에 맞춰 돈다 | |
| 1-6 | 매직리모컨 포인터로 시작 버튼을 클릭해도 시작된다(새로고침 후) | |
| 1-7 | 5분 이상 두어도 화면 보호기·절전으로 꺼지지 않는지(꺼지면 메모) | |
| 1-8 | 고양이 움직임이 끊기지 않는다(프레임 끊김 정도 메모) | |

## 2. Galaxy S26 — Chrome / 삼성 인터넷 (각각)

| # | 확인 | Chrome | 삼성 |
|---|---|---|---|
| 2-1 | 카메라로 TV QR 스캔 → 코드 입력칸 없이 큰 ▶ 버튼만 보인다 | | |
| 2-2 | ▶ 탭 → (권한 창이 뜨면 허용) → 전체화면 + 고양이가 크게 보인다 | | |
| 2-3 | TV 코드 칸 아래에 폰 아이콘(주황 막대)이 1개 늘었다 | | |
| 2-4 | 살짝 흔들면 TV에서 "둥" + 고양이 점프 + 음표, 폰 고양이도 통통 + 짧은 진동 | | |
| 2-5 | 세게 흔들면 소리가 더 크고 "야옹"도 섞인다 | | |
| 2-6 | 가만히 들고 있거나 천천히 걸을 때는 소리가 나지 않는다 | | |
| 2-7 | 아주 빠르게 흔들어도 소리가 박자에 맞춰 정리되어 난다(난장판이 아님) | | |
| 2-8 | 흔든 뒤 TV 소리까지 지연이 거슬리지 않는다(체감 메모) | | |
| 2-9 | 두 손가락으로 확대가 안 된다, 더블탭 확대가 안 된다 | | |
| 2-10 | 뒤로가기(제스처/버튼) 한 번으로 화면이 나가지 않는다 | | |
| 2-11 | 5분 이상 흔들지 않아도 화면이 꺼지지 않는다(Wake Lock) | | |
| 2-12 | 주소창에 `<터널주소>/p` → 코드 직접 입력 → ▶ → 입장된다 | | |
| 2-13 | 틀린 코드(예: 1000) 입력 → 입력칸이 빨갛게 흔들리고 입장 안 됨 | | |

## 3. iPhone 16 Pro — Safari

| # | 확인 | 결과 |
|---|---|---|
| 3-1 | 카메라로 QR 스캔 → Safari에서 큰 ▶ 버튼 | |
| 3-2 | ▶ 탭 → **"동작 및 방향 접근" 권한 창** → 허용 → 고양이 화면 | |
| 3-3 | 흔들면 TV에서 소리·움직임(2-4~2-8과 같은 기준) | |
| 3-4 | 진동은 없음(정상), 전체화면은 안 됨(Safari 제한, 정상) | |
| 3-5 | 확대·더블탭 확대·뒤로 스와이프로 나가지 않는다 | |
| 3-6 | 화면이 자동으로 꺼지지 않는다(iOS 16.4+ Wake Lock) | |
| 3-7 | 권한 창에서 **허용 안 함** 선택 시: 고양이를 탭하면 대신 연주된다(아이가 실패하지 않음) | |
| 3-8 | 권한을 거부한 뒤 다시 허용하려면: Safari 탭 닫고 다시 접속(메모) | |
| 3-9 | **코드를 직접 입력해 입장**한 뒤 세게 흔들어도 "실행 취소" 시스템 창이 뜨지 않는다 | |

## 4. 함께 놀기·끊김

| # | 확인 | 결과 |
|---|---|---|
| 4-1 | S26 + iPhone 동시에 흔들기 → 둘 다 TV에서 연주된다, 폰 아이콘 2개 | |
| 4-2 | 폰 와이파이를 껐다 켜기 → 고양이가 잠깐 회색 → 다시 컬러, 흔들면 다시 연주(코드 재입력 없음) | |
| 4-3 | TV 페이지 새로고침 → **같은 코드**로 돌아오고, 폰은 그대로 연주된다 | |
| 4-3b | TV 와이파이(또는 공유기)를 10초 끊었다 연결 → 같은 코드로 돌아오고, 폰은 그대로 연주된다 | |
| 4-4 | TV 브라우저를 닫고 1분 넘게 기다림 → 폰이 코드 입력 화면으로 돌아간다 | |
| 4-5 | 폰 화면을 껐다 켜기 → 계속 연주된다, 화면 꺼짐 방지도 다시 켜진다 | |
| 4-6 | 5살·2살이 실제로 흔들어 봄: 2살이 흔들어도 소리가 나는지(너무 둔하거나 예민하면 메모) | |

## 기록할 것
- 흔들림 민감도(2살 기준 너무 둔함/적당/예민) → 조정값은 `shared/shake.js`의 `SHAKE_THRESHOLD`
- 체감 지연, 소리 크기, TV 프레임 끊김
- 브라우저별 차이(특히 삼성 인터넷, webOS)
