# 실기기 테스트 체크리스트 (3단계: 동물 밴드)

대상: LG 75QNED90(webOS 6.5 브라우저), Galaxy S26(Chrome, 삼성 인터넷), iPhone 16 Pro(Safari).
각 항목 옆 칸에 ○/✕와 메모를 적는다. 문제가 나오면 `docs/harness-log.md`에도 한 줄 남긴다.

## 0. 준비

| # | 확인 | 결과 |
|---|---|---|
| 0-1 | `docs/setup.md` 순서대로 Render 배포 완료, `https://<내 주소>/healthz` → `ok` | |
| 0-2 | TV·폰이 모두 인터넷에 연결됨(같은 와이파이가 아니어도 됨) | |

> 센서 권한은 HTTPS에서만 나온다. Render 주소는 `https://`라 그대로 쓰면 된다.
> 15분 넘게 안 쓰면 서버가 잠들어, 첫 접속에 약 1분 걸린다.

## 진단 모드 (문제가 생기면 먼저 켜기)

TV 주소 끝에 `?debug`를 붙여 연다(예: `https://<내 주소>/tv/?debug`). TV 왼쪽 아래에 진단 화면이 나오고, QR에도 자동으로 붙어 폰도 진단 화면으로 열린다.

| 화면 | 볼 것 | 이상하면 |
|---|---|---|
| TV `오디오` | `WebAudio running` | `suspended`면 시작 버튼을 다시 누름. `HTML5 Audio`면 webOS가 WebAudio를 막는 것 → 알려 주기 |
| TV `FPS` | 30 이상 | 20 미만이면 끊김 원인 → 알려 주기 |
| TV `흔들기` | `받음`이 폰 흔들기 수만큼 늘고, `연주`는 박자당 1번 | `받음`이 안 늘면 네트워크 문제, `받음`은 느는데 소리가 없으면 오디오 문제 |
| 폰 `권한` | `granted` 또는 `필요 없음` | `denied`면 Safari 탭 닫고 다시 접속 |
| 폰 `샘플` | 50~60Hz 안팎 | 0Hz면 센서 값이 안 옴(권한·HTTPS 확인) |
| 폰 그래프 | 흔들 때 초록 선이 빨간 선(임계값)을 넘고 노란 세로줄(판정)이 생김 | 아이가 흔들어도 안 넘으면 `−`로 임계값을 낮춤, 걸을 때도 넘으면 `+` |
| 폰 `화면유지` | `켜짐` | `실패`·`미지원`이면 화면 꺼짐 방지가 안 됨 |
| 양쪽 `왕복` | 100ms 이하 | 크면 와이파이·인터넷 지연(Render 서버는 싱가포르) |

**결과 보내기:** Render 대시보드 → 서비스 → **Logs**에 `[tv 1234] report: …`, `[phone 1234] report: …`, `error: …` 줄이 쌓인다. 문제가 난 시점 전후 줄을 복사해 그대로 보내 주면 원인을 찾을 수 있다. 임계값을 바꿨다면 `임계값 변경 → 13.5` 줄의 값을 알려 주면 기본값으로 반영한다.

## 1. TV — webOS 6.5 브라우저

| # | 확인 | 결과 |

| 1-5 | 시작 후 QR·코드가 오른쪽 위로 작아지고, 바닥의 불빛 4개가 박자에 맞춰 돈다 | |
| 1-6 | 매직리모컨 포인터로 시작 버튼을 클릭해도 시작된다(새로고침 후) | |

## 4. 함께 놀기·끊김

| # | 확인 | 결과 |
|---|---|---|

| 4-4 | TV 브라우저를 닫고 1분 넘게 기다림 → 폰이 코드 입력 화면으로 돌아간다 | |

## 5. 펭귄 밴드 (2단계)

| # | 확인 | 결과 |
|---|---|---|
| 5-1 | TV 시작(OK) → 배경 반주가 작게 흐르고, 박자 불빛과 맞는다 | |
| 5-2 | 폰이 없는 펭귄은 눈 감고 졸고 있다. 폰이 들어오면 그 펭귄이 깨어나 깡충 | |
| 5-3 | 폰마다 다른 펭귄이 화면에 크게 나온다(1번 빨간 목도리·드럼, 2번 파란 모자·탬버린, 3번 노란 리본·실로폰, 4번 초록 헤드폰·마라카스) | |
| 5-4 | 흔들면 그 폰의 펭귄만 자기 악기로 연주. 실로폰은 흔들 때마다 다음 음(짧은 멜로디) | |
| 5-5 | 여럿이 함께 흔들면 악기가 겹쳐 합주처럼 들린다(소리가 너무 크거나 지저분하면 메모) | |
| 5-6 | 폰을 새로고침해도 같은 펭귄으로 돌아온다 | |
| 5-7 | **꽥 버튼**: 누르면 TV에서 "꽥꽥" + 그 펭귄이 흔들며 뛰고 별이 터짐. 마구 눌러도 1초에 1번 | |
| 5-8 | 꽥 소리가 펭귄처럼 들리나?(이상하면 어떻게 이상한지 메모) | |
| 5-9 | **마이크 버튼(처음)**: 누르면 마이크 권한 창 → 허용. 첫 번째는 권한 때문에 녹음이 안 될 수 있음(정상) | |
| 5-10 | **누르고 말하기**: 버튼을 누른 채 말하기(버튼이 커지며 깜빡) → 떼면 1~2초 뒤 TV에서 높은 펭귄 목소리 + 그 펭귄이 고개 까딱 | |
| 5-11 | 말하는 동안 TV 배경 반주가 작아졌다가 끝나면 돌아온다 | |
| 5-12 | 5초 넘게 누르고 있으면 5초에서 저절로 보내진다 | |
| 5-13 | 살짝 톡 누르기(0.3초 미만)는 보내지 않는다 | |
| 5-14 | **하울링**: TV 가까이에서 말해도 "삐이익" 소리가 나지 않는다 | |
| 5-15 | iPhone: 마이크 사용 중 표시(주황 점)가 놀이 화면을 떠나면 꺼진다 | |
| 5-16 | 마이크 권한을 거부하면 마이크 버튼이 회색으로 바뀌고, 흔들기·꽥은 그대로 된다 | |
| 5-17 | **iPhone**: 마이크 첫 누르기(권한) → 두 번째 누르고 말하기 → TV에서 재생된다. 안 되면 진단 화면 `마이크` 값(예: `켜짐(suspended)`)을 메모 | |
| 5-18 | 말하고 15초 동안 안 쓰면 마이크 사용 표시가 꺼진다(다시 누르면 다시 켜짐) | |

> 알려진 한계: 와이파이가 끊겼다 바로 붙으면(서버가 옛 연결을 아직 정리하기 전) 폰이 다른 펭귄을 받을 수 있다. 잠시 뒤 새로고침하면 원래 펭귄으로 돌아온다.

## 6. 동물 고르기 (3단계)

| # | 확인 | 결과 |
|---|---|---|
| 6-1 | 폰 화면 동물 아래에 ◀ ▶ 큰 버튼이 있다. ▶를 누르면 다음 동물로 바뀌고 특별 버튼 얼굴도 바뀐다 | |
| 6-2 | 동물 순서: 펭귄 4마리 → 곰 → 토끼 → 오리 → 고양이 → 처음으로. 다른 폰이 쓰는 동물은 건너뛴다 | |
| 6-3 | 바꾸면 TV에서 그 자리가 "펑" 하고 새 동물로 바뀌며 깡충 + 그 동물 소리 한 번 | |
| 6-4 | 곰: 흔들면 낮은 큰북, 특별 버튼 "어흥", 목소리가 **낮고 굵게** | |
| 6-5 | 토끼: 트라이앵글 "띵", 특별 버튼 "뿅", 목소리 아주 높게 | |
| 6-6 | 오리: 나팔 "빠-"(흔들 때마다 다음 음), 특별 버튼 "꽥꽥", 목소리 높게 | |
| 6-7 | 고양이: 핸드벨(흔들 때마다 다음 음), 특별 버튼 "야옹" | |
| 6-8 | 폰 새로고침해도 고른 동물 그대로 | |
| 6-9 | ◀ ▶를 마구 눌러도 화면이 엉키지 않는다(0.3초에 1번만 바뀜) | |
| 6-10 | 2살이 ◀ ▶를 눌러도 동물만 바뀌고, 흔들면 그대로 연주된다 | |
| 6-11 | 각 소리가 동물처럼 들리나?(이상한 소리 메모: 어떤 동물, 어떻게) | |

## 기록할 것
- 흔들림 민감도(2살 기준 너무 둔함/적당/예민) → 진단 모드의 `−`/`+`로 맞춘 임계값
- 체감 지연, 소리 크기, TV 프레임 끊김
- 브라우저별 차이(특히 삼성 인터넷, webOS)
